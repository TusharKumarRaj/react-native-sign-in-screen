# React Native Sign In Screen

A simple and clean sign-in screen built with React Native and Expo.

## Features

- Email and password login form
- Social login options (Facebook, Google, Instagram)
- Light and dark mode support
- Sign up and password recovery links
- Responsive design

## Preview

![Sign In Screen](./page_image.jpg)

## Getting Started

### Install dependencies

```bash
npm install
```

### Start the app

```bash
npx expo start
```

Then press:

- **a** for Android emulator
- **i** for iOS simulator
- **w** for web browser
- **j** to open Expo Go on your phone
